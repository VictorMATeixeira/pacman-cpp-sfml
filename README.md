# 🕹️ Pac-Man (Trabalho 3 - INF110)

Um clone moderno e funcional do clássico arcade **Pac-Man**, desenvolvido em **C++** utilizando a biblioteca gráfica **SFML**.

## 🎓 Contexto Acadêmico

Este projeto foi proposto pelo professor **André Gustavo** durante o primeiro período do curso de **Ciência da Computação** na **Universidade Federal de Viçosa (UFV)**. O objetivo principal foi aplicar de forma prática e robusta os conceitos de lógica de programação e estruturação de software aprendidos durante o semestre.

---

## 🛠️ Tecnologias e Recursos Utilizados

* **Linguagem:** C++
* **Biblioteca Gráfica/Áudio:** SFML (Simple and Fast Multimedia Library)
* **Mecânicas Implementadas:**
  * Movimentação e detecção de colisão baseadas em grade (*Grid/Matrix*)
  * Fantasmas com comportamentos, efeitos visuais e sprites customizados
  * Sistema de pontuação (*Score* e *High Score*)
  * Coleta de pílulas (*Pellets*) e mecânicas de *Power-Ups*
  * Teleporte nos túneis laterais do mapa
